Lesson 01 / Navigation

Explore the File System

Linux organizes files in a directory tree. Your terminal starts in a working directory.

student@linux:~$ pwd /home/student student@linux:~$ ls Documents Downloads Pictures student@linux:~$ cd Documents

Lesson 02 / Create

Create Files & Folders

Use mkdir to create a directory and touch to create an empty file.

student@linux:~$ mkdir Linux_Lab student@linux:~$ cd Linux_Lab student@linux:~/Linux_Lab$ touch notes.txt student@linux:~/Linux_Lab$ ls notes.txt

Lesson 03 / Organize

Copy & Move

Copy a file without changing the original, or move/rename it with mv.

student@linux:~/Linux_Lab$ cp notes.txt copy.txt student@linux:~/Linux_Lab$ mv copy.txt final.txt student@linux:~/Linux_Lab$ ls final.txt notes.txt

Lesson 05 / Clean Up

Remove Safely

Delete files and empty directories carefully. Terminal deletion usually bypasses the Trash.

student@linux:~/Linux_Lab$ rm final.txt student@linux:~/Linux_Lab$ mkdir empty_folder student@linux:~/Linux_Lab$ rmdir empty_folder
